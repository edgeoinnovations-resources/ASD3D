# ASD Campus 3D

Interactive 3D model of the American School of Dubai campus, built from the school's CAD floor plans,
site plan, 2019 SketchUp massing model and the F Block 3D model, georeferenced to WGS 84 / UTM zone 40N.

Live site: https://edgeoinnovations-resources.github.io/ASD3D/

Static page (three.js). Models ship as glTF JSON with embedded buffers; `data.json` holds the room polygons.
